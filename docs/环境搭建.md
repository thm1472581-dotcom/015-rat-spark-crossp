下面按“**从零搭环境 → 编译 → 最终执行脚本**”给你梳理一遍。你最后要跑的核心脚本就是 `build.all.bat`（全量构建），它内部会依次调用前端、statik、客户端、服务端、打包 deploy。

---

## 1. 需要安装的软件

| 软件 | 版本建议 | 说明 |
|------|----------|------|
| Git | 任意 | 拉代码、取 commit 号 |
| Go | **1.18+** | 编译 server / client |
| Node.js | **16+**，推荐 18 LTS | 编译 web 前端 |
| npm | 随 Node 安装 | 安装前端依赖 |
| statik | latest | 把前端静态资源嵌进 Go |

验证命令（PowerShell / CMD 均可）：

```powershell
git --version
go version
node -v
npm -v
```

---

## 2. 安装 Go

1. 下载安装包：https://go.dev/dl/  
   选 Windows amd64 的 `.msi`，一路默认安装即可（默认会装到 `C:\Program Files\Go`）。
2. 安装后**新开一个终端**，确认：

```powershell
go version
```

3. 配置国内代理（你文档里也有）：

```powershell
go env -w GOPROXY=https://goproxy.cn,https://mirrors.aliyun.com/goproxy/,https://goproxy.io,direct
```

4. 确认 Go 的 bin 目录在 PATH 中。默认是：

```
%USERPROFILE%\go\bin
C:\Program Files\Go\bin
```

`build.all.bat` 里已经自动把这两个路径加进 PATH，所以一般不用手动配。

---

## 3. 安装 Node.js + npm

1. 下载 LTS 版：https://nodejs.org/  
   推荐 **18 LTS**，Windows Installer `.msi`，默认安装。
2. 安装后新开终端验证：

```powershell
node -v
npm -v
```

3. 可选：换 npm 淘宝源，加速安装：

```powershell
npm config set registry https://registry.npmmirror.com
```

---

## 4. 安装 statik

```powershell
go install github.com/rakyll/statik@latest
```

安装完检查：

```powershell
where statik
```

正常应输出：

```
C:\Users\你的用户名\go\bin\statik.exe
```

如果 `where statik` 找不到，把 `%USERPROFILE%\go\bin` 加到系统 PATH，或者直接用全路径。  
`build.all.bat` 里已经做了兜底：找不到 `statik` 时会尝试用 `%USERPROFILE%\go\bin\statik.exe`。

## 6. 最终执行的脚本

你最终只需要跑 `scripts\build.all.bat`。  
它内部流程是：

```
[1/5] web 前端 build        -> web\dist
[2/5] statik 嵌入           -> server\embed\web\statik.go
[3/5] 编译 client 模板      -> built\
[4/5] 编译 server           -> releases\server_windows_amd64.exe
[5/5] 打包 deploy           -> deploy\
```

### 执行方式

```powershell
cd A:\000-work\001-project\158-remote-control\102-rat-spark-crossp\scripts
.\build.all.bat
```

如果前端依赖已经装过，想跳过 `npm install`：

```powershell
.\build.all.bat skip-npm
```

### 脚本执行前建议确认

1. Go、Node、npm、Git、statik 都已安装且在 PATH。
2. 当前目录在项目根下的 `scripts`，脚本内部会 `cd /d "%~dp0.."` 回到项目根。
3. 磁盘有足够空间，`built\`、`releases\`、`deploy\` 会自动创建。

---

## 7. 脚本执行成功后

你会得到：

```
releases\server_windows_amd64.exe
deploy\                             (可直接运行)
```

启动服务端：

```powershell
cd deploy
run.bat
```

或者手动：

```powershell
.\server_windows_amd64.exe -config config.json
```

然后浏览器访问：

```
http://<服务器IP>:8000/
```

用 `config.json` 里的 `auth` 账号登录，进入 Overview → 生成客户端，下载后在目标机运行即可上线。

## 8. 常见问题速查

| 现象 | 原因 / 处理 |
|------|-------------|
| `statik not found` | 没装 statik，或 `%USERPROFILE%\go\bin` 不在 PATH |
| `npm install failed` | Node/npm 没装好，或网络问题，换 npmmirror 源 |
| `web\dist\index.html not found` | 前端 build 失败，单独进 `web` 跑 `npm run build-prod` 看报错 |
| `server\embed\web\statik.go not generated` | statik 命令失败，检查 `web\dist` 是否存在 |
| `built\windows_amd64 not found` | `build.client.bat` 失败，单独跑看具体报错 |
| `go build server failed` | 检查 `Spark/server` 路径、`go mod tidy` 是否成功 |
| Linux 目标编译报路径错误 | 文档提到 `build.server.bat` 里 Linux 目标误写为 `Spark/Server`，改成 `Spark/server` |
